# RPG Character Sheet — Java + MySQL + Python

Este é um projeto de portfólio que integra três tecnologias para criar uma ficha de personagem de RPG interativa. 

O sistema coleta os atributos do personagem via interface gráfica (Java Swing), salva os dados em um banco de dados MySQL e, em seguida, chama um script Python para gerar um gráfico de radar (teia) com as habilidades do personagem.

## 🛠️ Tecnologias Utilizadas
- **Java 25** (Swing, JDBC)
- **MySQL** (Banco de dados relacional)
- **Python 3** (Matplotlib, Numpy)
